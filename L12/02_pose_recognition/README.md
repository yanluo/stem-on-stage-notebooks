# Project 2 — Pose recognition

> **Classify body posture (upright / bending / lying / tilted) from the micro:bit's pitch and roll.**

## What's in here

- [`pose_starter.ipynb`](pose_starter.ipynb) — load sample CSV → plot → rule-based classifier → 2D region plot.
- [`wearable_pose.py`](wearable_pose.py) — MakeCode Python program that runs **live on the device** and shows a different LED icon per pose.
- [`../../data/sample-pose.csv`](../../data/sample-pose.csv) — 30 s synthetic recording walking through all four poses. Generated by [`generate_sample_pose.py`](../../data/generate_sample_pose.py).

## Why this project is interesting

It's the only L12 starter where **a single sensor reading is enough** — no windowing, no machine learning, no train/test split. Pitch + roll fully describe orientation, so an `if/elif` ladder gets you to a working classifier in 6 lines.

That makes it the fastest path from "no code" to "lantern reacts to dancer's posture in real time."

## What you need

- 1× micro:bit v2.
- A way to mount it **flat with the LED matrix facing up** — on top of the wrist (like a wide watch on the back of the hand) or on top of a baseball cap. *Not* held vertically against the chest: pitch and roll are derived from gravity and only behave intuitively when the board's Z axis is roughly vertical.
- A laptop with Colab access (for the notebook side).

## Mounting (recommended: wrist)

Lay the board flat on top of the wrist, LED matrix facing the ceiling, logo pointing forward (away from the body). Hold the arm out, palm down. From this neutral pose:

- *Bending* analog → tip the hand fingers-down (pitch goes large negative).
- *Lying on side* analog → twist the wrist thumb-up (roll grows past ±40).
- Anything else → falls into the catch-all *tilted* class.

A baseball-cap mount works the same way: board flat on top, logo pointing toward where the nose points; head tips → pitch changes; head tilts onto a shoulder → roll changes.

## What to build next (pick one as your L13 goal)

1. Capture your own pose CSV by extending the L11 datalogger to log `pitch,roll` instead of `x,y,z`.
2. Add a new pose class — e.g. *arms-up* with the wrist mount, or *head-back* with a cap mount. New pose, new threshold rule.
3. Drive a **NeoPixel color** from pose — upright = white, bending = blue, lying = off, tilted = yellow.
4. **Smooth the prediction** with a 1-second majority vote so brief stumbles don't flicker the lantern.
5. **Per-dancer calibration** — record 5 s of each dancer's natural "upright" and store the offset.

## Tuning the thresholds

The starter uses ±15° (upright deadband), −25° (bending), and ±40° (lying). These are tuned to a real wrist mount, but every wrist is different and every cap sits a little differently. The notebook's 2D pitch-vs-roll plot is the right tool to pick better cuts — drop your captured points on it and draw the dividing lines by eye. The wearable also streams `pitch` / `roll` to the MakeCode console, so you can read the actual numbers while doing each pose.
